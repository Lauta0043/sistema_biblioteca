# 📌 El orden que yo seguiría para aprenderlo

Y esto es importante para **no caer nuevamente en el problema de tener cinco tecnologías mezcladas en la cabeza**.

No estudies:

```text
HTML
CSS
PHP
JavaScript
SQL
```

simultáneamente.

Estudiá así:

```text
1. SQL
   ↓
2. PHP + SQL
   ↓
3. HTML + PHP
   ↓
4. CRUD
   ↓
5. Sesiones
   ↓
6. Reglas de negocio
   ↓
7. JavaScript
   ↓
8. AJAX / fetch
   ↓
9. CSS / diseño
```

Y el proyecto va creciendo de esta manera:

```text
BASE DE DATOS
      ↓
CONEXIÓN PHP
      ↓
HTML + PHP
      ↓
CRUD LIBROS
      ↓
CRUD USUARIOS
      ↓
PRÉSTAMOS
      ↓
DEVOLUCIONES
      ↓
DASHBOARD
      ↓
JAVASCRIPT
      ↓
SEGURIDAD
      ↓
PRUEBAS
```

### 🎯 Tu primer objetivo no debería ser "hacer el sistema"

Debería ser llegar a esto:

```text
[ PHP ]

    ↓

[ MySQL ]

    ↓

SELECT usuarios

    ↓

PHP recibe resultados

    ↓

HTML muestra usuarios
```

Cuando entiendas **ese recorrido**, el resto del sistema deja de ser un monstruo. Después simplemente vas agregando operaciones y reglas sobre la misma estructura.
